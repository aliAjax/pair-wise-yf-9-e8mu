# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 今晚复习清单

- 在收藏卡片或游戏详情上点“加入今晚清单”，挑出聚会要复习的游戏。
- 清单按先后顺序排列，可用 ↑/↓ 按钮或拖动整行调整顺序。
- 每条规则带勾选框，逐条确认；顶部进度条显示总进度，单款全部确认后高亮。
- 勾选与当时的规则文本绑定：**规则被删除、或内容被修改后，对应勾选立即失效**，不会出现“已经确认过”的假象，需要重新确认。
- 清单顺序和勾选进度都保存在浏览器 localStorage，关闭页面再打开仍然保留。
