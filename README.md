# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 今晚复习清单

- 在收藏卡片或详情页点「加入今晚」，挑出今晚要玩的游戏，用 ↑/↓ 排成聚会先后顺序。
- 逐条勾选已确认的规则，顶部进度条显示完成度。
- 清单以加入时的规则内容为快照：准备期间某条规则被删除，或提醒内容被改写（规则行新增 ✎ 行内编辑），对应勾选立即失效，并在清单底部单列出来提示复核，不会保留“已完成”的假象；游戏里新补充的规则会自动追加为未勾选条目。
- 清单顺序与勾选进度保存在 localStorage，关掉页面再打开仍在。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
